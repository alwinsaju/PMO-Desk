PMO Desk mark: a rounded teal tile (your own device) holding a "P" built from a queue and a checkpoint.
The stem is three stacked pills that fade, the items waiting in the Review Queue; the bowl is a ring with a tick, the single approval gate.
Files: mark.svg (default, light or dark pages), mark-dark.svg (light tile for dark artwork), mark-mono.svg (one colour via currentColor), wordmark.svg / wordmark-dark.svg, PNG exports mark-512.png and mark-32.png.
Colours come from src/styles/tokens.css (accent 600/700 and the dark-mode accent); keep clear space of a quarter of the tile width and do not go below 16px.
The wordmark text uses Figtree 800 and falls back to Segoe UI if the font is not installed; use the mark alone where the font is unavailable.
